# 幫 AI 上三道鎖：讓你敢放手開全自動

## 兩種用法，挑一個就好

### 🟢 懶人法（推薦，不用懂技術）

**複製這一頁的網址，貼給你的 Claude 或 ChatGPT**，然後說：

> 請讀這個網址的內容，一步一步帶我設定，我完全不懂技術。

它會自己讀懂，然後像老師一樣帶你做完，全程大約 10 分鐘。它會先問你用 Windows 還是 Mac。

### 🔧 自己動手

直接往下看，所有程式碼區塊都可以複製。
**順序請照 第二道 → 第三道 → 第一道**，理由寫在下面「安裝順序」那段。

---

## 給 AI 的執行指示

> 這一段是寫給 AI 看的。如果你是人類，可以直接跳到下面的「安裝順序」。

你現在是安裝助手。使用者是**完全不懂技術的一般人**，請依照以下規則帶他完成設定：

1. **一次只給一個步驟**，等他回覆完成再給下一步。不要一次貼一大串。
2. **每個指令都先用白話說它會做什麼**，再給指令。不要只丟指令。
3. **開始前先問他用 Windows 還是 Mac**，兩邊步驟不同。
4. **他卡住時換更簡單的講法重講**，不要跳過、不要要求他自己查。
5. **不要使用任何技術術語**。說「紅線清單」不要說 deny rules，說「設定檔」不要說 JSON。
6. 全程使用**繁體中文**。

### ⚠️ 最重要的一條

第二道鎖需要修改 `settings.json`。**使用者很可能已經有這個檔案，裡面有他既有的設定。**

你必須：
- 先讀取現有檔案內容
- 把 `deny` 清單**合併**進去，保留其他所有既有設定
- **絕對不要整份覆蓋**

如果覆蓋掉，他既有的設定會全部消失。這是這份文件裡最容易出事的地方。

## 第二道鎖：紅線清單（必裝，5 分鐘）

### 白話說明（請這樣跟使用者解釋）

> 這是一張禁止清單。清單上的指令，AI 一輩子碰不到，就算它自己想跑也會被系統擋下來。
> 上面這些都是「一按下去就救不回來」的操作，例如整個資料夾砍掉、強制覆蓋你的工作進度、關機。

### 檔案位置

- **Windows**：`C:\Users\<使用者名稱>\.claude\settings.json`
- **Mac**：`~/.claude/settings.json`

### 要加入的內容

在 `permissions` 底下加入 `deny` 清單。完整 20 條：

```json
{
  "permissions": {
    "deny": [
      "Bash(rm -rf *)",
      "Bash(rm -fr *)",
      "Bash(rm -r *)",
      "Bash(rm -R *)",
      "Bash(rm -f *)",
      "Bash(sudo *)",
      "Bash(dd *)",
      "Bash(mkfs*)",
      "Bash(diskutil erase*)",
      "Bash(chmod 777 *)",
      "Bash(chmod -R 777 *)",
      "Bash(git reset --hard*)",
      "Bash(git push --force*)",
      "Bash(git push -f *)",
      "Bash(git clean -f*)",
      "Bash(git branch -D*)",
      "Bash(shutdown*)",
      "Bash(reboot*)",
      "Bash(: >*)",
      "Bash(truncate *)"
    ]
  }
}
```

### 這 20 條各在擋什麼（使用者問起時這樣答）

| 擋掉的東西 | 白話 |
|---|---|
| 前 5 條 | 整個資料夾連同裡面的檔案一次砍光 |
| sudo | 用最高權限做事，出錯範圍最大 |
| dd / mkfs / diskutil erase | 直接對硬碟動手，會整顆清空 |
| chmod 777 | 把檔案權限全開，等於門戶大開 |
| git 那 5 條 | 強制覆蓋或丟掉你的工作進度，救不回來 |
| shutdown / reboot | 直接關機重開，你手上沒存的東西全沒 |
| 最後 2 條 | 把檔案內容清空，檔案還在但變空的 |

### 驗證方式（不要真的執行危險指令）

改完之後請使用者重開 Claude Code，然後叫 AI 執行一條清單上的指令。
**正確結果**：跳出被擋下來的訊息，指令沒有真的跑。
如果沒被擋，代表檔案位置錯了或格式壞了，回頭檢查。

## 第三道鎖：權限模式（必裝，1 分鐘）

### 白話說明

> 這是設定 AI 的權限等級：改檔案不用問你，但要動系統指令，一定要先舉手等你點頭。
> 這樣它做事順暢，但關鍵時刻停下來等你。

### 做法

在同一個 `permissions` 區塊裡加一行：

```json
"defaultMode": "acceptEdits"
```

完整長這樣：

```json
{
  "permissions": {
    "deny": [ ...上面那 20 條... ],
    "defaultMode": "acceptEdits"
  }
}
```

### 四種模式差別（使用者問起時這樣答）

| 模式 | 白話 | 適合誰 |
|---|---|---|
| `plan` | 只能看和想，什麼都不能動 | 完全不放心的人 |
| `default` | 每件事都要問你 | 新手，但會問到你煩 |
| `acceptEdits` | 改檔案不問，跑指令要問 | **推薦，多數人用這個** |
| `bypassPermissions` | 什麼都不問 | 已經裝好紅線清單、且知道自己在做什麼 |

## 第一道鎖：垃圾桶（進階選配）

### 白話說明

> 幫 AI 裝一個垃圾桶。裝完之後它刪掉的東西不會人間蒸發，是掉進垃圾桶，隨時撿得回來。

### Mac

```bash
brew install trash
```

裝完在 `~/.zshrc` 或 `~/.bashrc` 加：

```bash
alias rm='trash'
alias rm!='/bin/rm'
```

要永久刪除時改用 `rm!`。

### Windows

Windows 沒有原生的對應工具，需要先裝 WSL（在 Windows 裡跑一套 Linux）才能用同樣做法。

**請先問使用者：「你願意多花 20 分鐘裝一套額外環境嗎？不裝也沒關係，前兩道鎖已經擋掉主要風險。」**

- 他說不要 → 到此為止，告訴他已經完成，沒有損失
- 他說好 → 引導他安裝 WSL，然後在 WSL 裡用 `pip install trash-cli`，同樣加上面那兩行 alias

**不要預設他一定要裝。** 大部分人裝到一半就放棄了，前兩道鎖才是重點。

三道鎖裝完的實際差別：

- 以前每個指令都要盯著看、都要按確認，AI 在跑、你還在旁邊上班

**但要誠實提醒他**：這三道鎖擋的是常見誤操作，不是防毒軟體。重要的檔案還是要有備份或版本紀錄，這點不能省。

## ⚠️ 給使用者的資安提醒（請務必轉達）

`settings.json` 這個檔案裡**可能存有他的各種服務密碼和金鑰**（例如串接 Notion、Google 的憑證）。

所以：
- **絕對不要把整個 settings.json 檔案分享給任何人**，包括貼到網路上問問題
- 要分享只分享 `deny` 那 20 條清單
- 如果他不小心貼出去過，請提醒他去對應服務把金鑰重新產生一次
